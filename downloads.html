Get Marlin

The compiler, its standard library and runtime in one package for Linux, macOS and Windows. Free and open source under the MIT license.

Install with one command

The installer downloads the latest release for your machine, checks its SHA-256 checksum, puts it in your home folder and adds marlin to your PATH. Run it again to update.

Your system

Linux

x86-64 and ARM64 · glibc 2.28 or newer (Ubuntu 20.04, Debian 10, RHEL 8, Fedora, Arch …)

terminal
$ curl -fsSL https://github.com/MehmetEminKaymaz/marlin/releases/latest/download/install.sh | sh

You also need a C compiler: sudo apt install build-essential, sudo dnf install gcc or sudo pacman -S base-devel.

  • marlin-linux-x86_64.tar.gzx86-64
  • marlin-linux-arm64.tar.gzARM64
Your system

macOS

Apple silicon and Intel · macOS 11 Big Sur or newer

terminal
$ curl -fsSL https://github.com/MehmetEminKaymaz/marlin/releases/latest/download/install.sh | sh

You also need the Command Line Tools: xcode-select --install.

  • marlin-macos-arm64.tar.gzApple silicon
  • marlin-macos-x86_64.tar.gzIntel
Your system

Windows

Windows 10 and 11 · x64

PowerShell
PS> irm https://github.com/MehmetEminKaymaz/marlin/releases/latest/download/install.ps1 | iex

You also need Visual Studio Build Tools with C++ and Clang. One command installs them.

  • marlin-windows-x86_64.zipx64

Prefer to do it by hand? Download the archive for your system above, unpack it anywhere and add its bin folder to your PATH. On macOS, remove the browser's quarantine flag first: xattr -dr com.apple.quarantine marlin-*.

After installing

  1. Open a new terminal

    So that the PATH change takes effect.

  2. Check your setup

    marlin doctor compiles a few small programs and tells you what is missing, with the command to install it.

  3. Write and run

    You get a native executable. Continue with the guide.

terminal
$ marlin doctor

# hello.marl:  func main() -> void { print("hello, ocean"); }
$ marlin hello.marl -O2 -o hello
$ ./hello
hello, ocean

Syntax colouring, snippets, live errors from the real compiler and a one-key Compile & Run. Install Marlin first; the extension uses the marlin command.

Download marlin-vscode.vsix How to install it

Windows: Build Tools with Clang

Marlin links your programs with Clang and the Microsoft C libraries. If marlin doctor reports that the linker is missing, this installs both (about 3 GB):

PowerShell
PS> winget install Microsoft.VisualStudio.2022.BuildTools --override "--passive --add Microsoft.VisualStudio.Workload.VCTools --add Microsoft.VisualStudio.Component.VC.Llvm.Clang --includeRecommended"

Already have Visual Studio? Add the Desktop development with C++ workload and the C++ Clang tools for Windows component in the Visual Studio Installer instead.
